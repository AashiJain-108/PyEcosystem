# 01. Graph Fundamentals

## 1. What is a Graph?

A **Graph** is a mathematical structure used to represent relationships between different objects.

It consists of two fundamental components:

- **Vertices (Nodes):** Represent objects, entities or elements.
- **Edges:** Represent relationships or connections between those vertices.

For example, in a social network:
- People are represented as vertices.
- Friendships or connections are represented as edges.

Mathematically, a graph is represented as:

$$
G = (V,E)
$$

Where:

- $G$ = Graph
- $V$ = Set of vertices
- $E$ = Set of edges

Consider a simple graph:

$$
V = \{A,B,C,D\}
$$

$$
E = \{\{A,B\},\{A,C\},\{B,D\},\{C,D\}\}
$$

This graph contains four vertices and four edges.

## 2. Vertices (Nodes)

A **Vertex** (plural: Vertices), also commonly called a **Node**, represents an individual entity in a graph.

Examples:

| Application | What a vertex represents |
|---|---|
| Social Networks | A person |
| Transportation | A city or location |
| Computer Networks | A computer or router |
| Web Graphs | A webpage |
| Recommendation Systems | A user or product |

A graph can contain any number of vertices, including a graph with no vertices.

The number of vertices in a graph is called its **Order**.

$$
|V| = n
$$

Where $n$ represents the number of vertices.

## 3. Edges

An **Edge** represents a relationship or connection between two vertices.

For example, if two people are friends, an edge can represent their friendship.

Consider:

$$
e = \{A,B\}
$$

This represents a connection between vertices A and B in an undirected graph.

The number of edges in a graph is called its **Size**.

$$
|E| = m
$$

Where $m$ represents the number of edges.

## 4. Adjacent Vertices

Two vertices are called **Adjacent** if an edge directly connects them.

For example, if:

$$
E = \{\{A,B\},\{A,C\},\{B,D\}\}
$$

Then:

- A and B are adjacent.
- A and C are adjacent.
- B and D are adjacent.
- A and D are not adjacent.

## 5. Incident Edges

An edge is said to be **Incident** to a vertex if that vertex is one of the endpoints of the edge.

For example, consider:

$$
e = \{A,B\}
$$

The edge $e$ is incident to both A and B.

## 6. Degree of a Vertex

The **Degree** of a vertex is the number of edges incident to that vertex.

It is commonly represented by:

$$
\deg(v)
$$

For example, if vertex A is connected to B, C and D:

$$
\deg(A)=3
$$

In an undirected graph, the sum of the degrees of all vertices is twice the number of edges.

This is known as the **Handshaking Lemma**:

$$
\sum_{v \in V}\deg(v)=2|E|
$$

Each edge contributes one degree to each of its two endpoints.

## 7. Path

A **Path** is a sequence of vertices in which consecutive vertices are connected by edges.

For example:

$$
A \rightarrow B \rightarrow D \rightarrow E
$$

This is a path from A to E if the corresponding edges exist.

The **Length of a Path** is the number of edges traversed.

For the path above:

$$
\text{Path Length}=3
$$

## 8. Cycle

A **Cycle** is a closed path that starts and ends at the same vertex without repeating other vertices.

For example:

$$
A \rightarrow B \rightarrow C \rightarrow A
$$

This forms a cycle of length 3.

Cycles are important in studying network structures, dependency relationships and connectivity.

## 9. Neighbors

The **Neighbors** of a vertex are the vertices directly connected to it by an edge.

For example, if:

$$
E = \{\{A,B\},\{A,C\},\{A,D\}\}
$$

Then the neighbors of A are:

$$
N(A)=\{B,C,D\}
$$

## 10. Isolated Vertices

An **Isolated Vertex** is a vertex that has no edges connecting it to any other vertex.

Its degree is zero:

$$
\deg(v)=0
$$

Isolated vertices are useful to consider when analysing disconnected networks.

## Quick Recap

| Term | Meaning |
|---|---|
| Graph | A structure representing entities and their relationships |
| Vertex / Node | An individual entity |
| Edge / Links| A connection between vertices |
| Order | Number of vertices |
| Size | Number of edges |
| Adjacent Vertices | Vertices directly connected by an edge |
| Incident Edge | An edge connected to a vertex |
| Degree | Number of incident edges |
| Path | Sequence of connected vertices |
| Cycle | A closed path |
| Neighbors | Vertices directly connected to a given vertex |
| Isolated Vertex | A vertex with degree zero |

---

**Note:** These definitions primarily describe ordinary undirected graphs. Directed graphs require additional concepts such as in-degree and out-degree, which are covered in the next section.

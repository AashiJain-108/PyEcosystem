So lets start with very basics:

| Area | What it focuses on |
| :--- | :--- |
| **Graph Theory** | Mathematical study of graphs and their properties |
| **Graph Algorithms** | Step-by-step methods for solving graph problems |
| **Graph Computing** | Computational representation, processing and analysis of graph structures |
| **Graph Analytics** | Extracting insights and patterns from graph data |

These areas overlap significantly; they aren't completely separate disciplines.

For example:
- Graph Theory studies connectivity.
- Graph Algorithms provide BFS and DFS.
- Graph Computing implements these algorithms on computational graph representations.
- Graph Analytics uses the results to understand a real-world network.

**Real world scenarios were Graph Computing is being implemented:**
- Social Network Analysis: Discover communities, influential users and relationships.
- Transportation and Navigation: Find shortest routes and optimize transportation networks.
- Banking and Fraud Detection: Identify suspicious transaction patterns and relationships between accounts.
- Knowledge Graphs and AI: Represent relationships between entities, facts and concepts.
- Computer Networks: Study connectivity, network structure and communication paths.

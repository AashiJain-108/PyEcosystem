# 05. Graph Traversal

Graph traversal is the process of visiting vertices in a graph systematically.

Unlike a linear data structure, such as an array or linked list, a graph does not have a fixed sequential order. A vertex can connect to multiple other vertices, and those vertices can lead to further connections.

Therefore, we need specific algorithms to explore graphs.

The two fundamental graph traversal algorithms are:

1. Breadth-First Search (BFS)
2. Depth-First Search (DFS)

## 1. Breadth-First Search (BFS)

**Breadth-First Search (BFS)** explores a graph level by level.

It first visits the starting vertex, then visits all its immediate neighbors, followed by the neighbors of those vertices.

In other words, BFS explores nearby vertices before moving farther away.

### Example

Consider the following graph:

```text
        A
       / \
      B   C
     /   / \
    D   E   F
```

Starting from vertex A, BFS explores:

```text
Level 0: A
Level 1: B, C
Level 2: D, E, F
```

One possible traversal order is:

\[
A\rightarrow B\rightarrow C\rightarrow D\rightarrow E\rightarrow F
\]

The exact order depends on how neighbors are ordered.

### How BFS Works

BFS uses a **Queue** data structure.

A queue follows FIFO:

**First In, First Out**

The basic process:

1. Select a starting vertex.
2. Mark it as visited.
3. Insert it into the queue.
4. Remove the front vertex from the queue.
5. Visit its unvisited neighbors and insert them into the queue.
6. Repeat until the queue becomes empty.

### BFS Pseudocode

```text
BFS(Graph, start):

    Create an empty queue
    Mark start as visited
    Enqueue start

    While queue is not empty:

        vertex = Dequeue

        For each neighbor of vertex:

            If neighbor is not visited:

                Mark neighbor as visited
                Enqueue neighbor
```

### Time and Space Complexity

Using an adjacency list:

\[
\boxed{O(V+E)}
\]

Where:
- \(V\) = Number of vertices
- \(E\) = Number of edges

Space complexity:

\[
O(V)
\]

The queue and visited structure may collectively store up to \(O(V)\) vertices.

### Applications of BFS

- Finding shortest paths in unweighted graphs.
- Social network connection distances.
- Web crawling.
- Level-order exploration.
- Finding vertices within a given number of edges from a source.

**Important:** BFS finds shortest paths in terms of number of edges for unweighted graphs. It does not generally find minimum-weight paths in weighted graphs.

## 2. Depth-First Search (DFS)

**Depth-First Search (DFS)** explores a graph by going as deep as possible along one path before backtracking.

Instead of visiting all nearby vertices first, DFS follows one branch until it cannot continue, then returns to explore another branch.

### Example

Using the same graph:

```text
        A
       / \
      B   C
     /   / \
    D   E   F
```

One possible DFS traversal is:

\[
A\rightarrow B\rightarrow D\rightarrow C\rightarrow E\rightarrow F
\]

The exact order depends on the neighbor ordering and implementation.

### How DFS Works

DFS can be implemented using:

- A **Stack** data structure.
- Recursion, which uses the program's call stack.

A stack follows LIFO:

**Last In, First Out**

The basic process:

1. Select a starting vertex.
2. Mark it as visited.
3. Explore an unvisited neighbor.
4. Continue exploring deeper until no unvisited neighbor remains.
5. Backtrack to the previous vertex.
6. Continue until all reachable vertices have been explored.

### DFS Pseudocode

```text
DFS(Graph, vertex):

    Mark vertex as visited

    For each neighbor of vertex:

        If neighbor is not visited:

            DFS(Graph, neighbor)
```

### Time and Space Complexity

Using an adjacency list:

\[
\boxed{O(V+E)}
\]

Space complexity:

\[
O(V)
\]

This includes the visited structure and the recursion stack or explicit stack.

### Applications of DFS

- Detecting cycles in graphs.
- Finding connected components.
- Topological sorting of directed acyclic graphs.
- Maze solving.
- Identifying bridges and articulation points.
- Exploring all possible reachable vertices.

---

## 3. BFS vs. DFS

Both algorithms traverse graphs, but they explore them differently.

| Feature | BFS | DFS |
|---|---|---|
| Exploration | Level by level | Depth first |
| Data Structure | Queue | Stack / Recursion |
| Shortest Path | Finds shortest paths in unweighted graphs | Does not guarantee shortest paths |
| Backtracking | Not its primary strategy | Fundamental to exploration |
| Time Complexity | \(O(V+E)\) | \(O(V+E)\) |
| Space Complexity | \(O(V)\) | \(O(V)\) |

Neither algorithm is universally better. Their usefulness depends on the problem being solved.

## 4. Visited Set

Graphs can contain cycles, meaning traversal may encounter a vertex that has already been visited.

Without tracking visited vertices, an algorithm could repeatedly explore the same vertices.

A **visited set** keeps track of the vertices that have already been discovered or processed.

For example:

```text
A → B → C
↑       |
└───────┘
```

If we start at A, we can eventually encounter A again through C.

The visited set prevents the algorithm from repeatedly exploring A.

It is essential for correctly implementing BFS and DFS on general graphs.

## 5. Traversal in Disconnected Graphs

So far, we have started traversal from a single vertex.

However, a graph may contain multiple disconnected components.

Consider:

```text
A ─ B ─ C

D ─ E

F
```

Starting BFS or DFS from A will only visit:

\[
\{A,B,C\}
\]

It will not automatically visit D, E, or F.

To traverse every vertex in a disconnected graph, we need to start a new traversal from each unvisited vertex.

### General Approach

```text
For each vertex in Graph:

    If vertex is not visited:

        Start BFS or DFS from vertex
```

This approach ensures that every connected component is explored.

---

## 6. BFS and DFS in Weighted Graphs

BFS and DFS can also traverse weighted graphs.

However, they do not use edge weights to decide which path is shortest or cheapest.

For example, consider:

```text
A ──2── B ──2── D
 \             /
  └────10─────┘
```

There are two routes from A to D:

\[
A\rightarrow D=10
\]

\[
A\rightarrow B\rightarrow D=4
\]

BFS finds the route with the fewest edges, while DFS follows its exploration order.

For minimum total edge weight, we need algorithms such as:

- Dijkstra's Algorithm — non-negative edge weights.
- Bellman-Ford Algorithm — supports negative edge weights, provided there is no reachable negative-weight cycle when seeking finite shortest paths.

These will be covered in the Shortest Paths section.

## Quick Recap

| Concept | Key Idea |
|---|---|
| Graph Traversal | Systematically visiting vertices |
| BFS | Explores level by level |
| DFS | Explores deeply before backtracking |
| Queue | FIFO structure used by BFS |
| Stack | LIFO structure used by iterative DFS |
| Visited Set | Prevents repeated exploration |
| Disconnected Graph Traversal | Start a new traversal for each unvisited component |

## Why Graph Traversal Matters

Graph traversal is a foundation for many advanced graph algorithms.

For example:

- BFS helps calculate shortest paths in unweighted graphs.
- DFS helps identify cycles and structural properties.
- Both algorithms help explore connected components.
- Many advanced graph algorithms build on ideas introduced by BFS and DFS.

Understanding these two algorithms makes it easier to study shortest paths, connectivity, network analysis, and graph optimization.

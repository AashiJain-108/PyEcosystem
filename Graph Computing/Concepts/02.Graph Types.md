# 02. Graph Types

Graphs can be classified into different types depending on how vertices are connected, whether connections have directions, and whether multiple edges are allowed between the same pair of vertices.

## 1. Undirected Graph

An **Undirected Graph** is a graph in which edges do not have a specific direction.

If vertex A is connected to vertex B, the connection works in both directions.

For example, a friendship network:

- If A is friends with B, B is also friends with A.
- The relationship is mutual.

An undirected edge is represented as:

$$
\{A,B\} = \{B,A\}
$$

The order of vertices does not matter.

**Key Characteristics:**
- Edges have no direction.
- Connections are mutual.
- The degree of a vertex is the number of incident edges.

## 2. Directed Graph (Digraph)

A **Directed Graph**, also called a **Digraph**, is a graph in which every edge has a specific direction.

For example, consider a social media following network:

- A follows B.
- This does not necessarily mean B follows A.

A directed edge is represented as:

$$
(A,B) \neq (B,A)
$$

Here, the edge from A to B is different from the edge from B to A.

**Key Characteristics:**
- Edges have directions.
- Connections do not necessarily work both ways.
- Each vertex has an in-degree and an out-degree.

### In-Degree

The **In-Degree** of a vertex is the number of edges directed towards it.

$$
\deg^{-}(v)
$$

### Out-Degree

The **Out-Degree** of a vertex is the number of edges directed away from it.

$$
\deg^{+}(v)
$$

The total degree of a vertex in a directed graph is:

$$
\deg(v)=\deg^{-}(v)+\deg^{+}(v)
$$

## 3. Weighted Graph

A **Weighted Graph** is a graph in which edges have numerical values called **Weights**.

These weights represent some measurable property of the relationship between two vertices.

Examples:

| Application | Meaning of Edge Weight |
|---|---|
| Transportation | Distance between two cities |
| Computer Networks | Network latency |
| Social Networks | Strength of a relationship |
| Financial Networks | Transaction amount |
| Recommendation Systems | Similarity score |

For example, consider a transportation network:

$$
w(A,B)=10
$$

This could represent a distance of 10 kilometres between locations A and B.

**Key Characteristics:**
- Edges carry numerical values.
- Weights can represent distance, cost, strength or other quantities.
- Algorithms can use weights to calculate shortest or least-cost paths.

**Important:** A weight is not necessarily a distance or a cost. Its meaning depends on the application.

## 4. Unweighted Graph

An **Unweighted Graph** is a graph in which edges do not carry explicit numerical weights.

All edges are treated equally for unweighted graph operations.

For example, in a simple friendship network, we may only care whether two people are connected, rather than assigning a numerical strength to their friendship.

**Key Characteristics:**
- Edges represent connections without explicit weights.
- Every edge is treated equally when calculating path length.
- The length of a path is measured by the number of edges traversed.

## 5. Multigraph

A **Multigraph** is a graph that allows multiple edges between the same pair of vertices.

For example, consider two cities connected by multiple transportation routes:

- A railway connection.
- A road connection.
- Another alternative transportation route.

These represent different relationships between the same two vertices.

**Key Characteristics:**
- Multiple edges can connect the same pair of vertices.
- Each edge can represent a different relationship.
- Depending on the graph definition, edges may also carry individual attributes.

## 6. Simple Graph

A **Simple Graph** is an undirected graph that does not contain:

- Self-loops.
- Multiple edges between the same pair of vertices.

A self-loop is an edge that connects a vertex to itself.

For example:

$$
e = \{A,A\}
$$

This is a self-loop and is not allowed in a simple graph.

**Key Characteristics:**
- No self-loops.
- No parallel edges.
- Edges connect distinct pairs of vertices.

## 7. Self-Loops

A **Self-Loop** is an edge that connects a vertex to itself.

For example:

$$
e = (A,A)
$$

Self-loops can represent situations where an entity has a relationship with itself.

Examples:
- A webpage linking to itself.
- A state transitioning back to itself in a state machine.
- A transaction or event associated with the same entity as both endpoints.

Self-loops are allowed in many graph models, but not in simple graphs.

## 8. Complete Graph

A **Complete Graph** is a simple undirected graph in which every pair of distinct vertices is connected by an edge.

For a graph containing $n$ vertices, the number of edges in a complete graph is:

$$
|E|=\frac{n(n-1)}{2}
$$

For example, a complete graph with four vertices contains:

$$
|E|=\frac{4(4-1)}{2}=6
$$

**Key Characteristics:**
- Every vertex is connected to every other vertex.
- There are no missing edges between distinct vertices.
- Every vertex has degree $n-1$.

## 9. Connected and Disconnected Graphs

### Connected Graph

An **Undirected Graph** is called connected if there is a path between every pair of vertices.

In other words, every vertex can be reached from every other vertex.

### Disconnected Graph

A graph is called disconnected if at least one pair of vertices has no path connecting them.

A disconnected graph consists of two or more connected components.

**Key Characteristics:**
- Connected graphs have a path between every pair of vertices.
- Disconnected graphs contain separate components.
- An isolated vertex forms a connected component of its own.

## Quick Recap

| Graph Type | Main Characteristic |
|---|---|
| Undirected Graph | Edges have no direction |
| Directed Graph | Edges have a direction |
| Weighted Graph | Edges carry numerical weights |
| Unweighted Graph | Edges have no explicit weights |
| Multigraph | Multiple edges can connect the same vertices |
| Simple Graph | No self-loops or parallel edges |
| Self-Loop | An edge connects a vertex to itself |
| Complete Graph | Every pair of distinct vertices is connected |
| Connected Graph | A path exists between every pair of vertices |
| Disconnected Graph | Some vertices cannot reach one another |

---

**Note:** These graph classifications are not mutually exclusive. A graph can be directed and weighted, or undirected and weighted, for example. The properties describe different aspects of graph structure.

- **Directed vs Undirected:** Is there a direction to an edge?
- **Weighted vs Unweighted:** Does an edge carry a numerical value?
- **Simple Graph vs Multigraph:** Are self-loops and multiple edges permitted?
- **Connected vs Disconnected:** Can every vertex be reached from every other vertex?

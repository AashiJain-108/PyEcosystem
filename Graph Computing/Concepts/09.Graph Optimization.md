# 09. Graph Optimization

Graph Optimization focuses on finding the best possible solution to a problem represented using a graph.

The objective may involve minimizing or maximizing something, such as:

* Minimizing total distance or cost.
* Minimizing the number of resources required.
* Maximizing network flow.
* Finding an efficient assignment of tasks.
* Selecting an optimal set of connections.

A graph optimization problem generally consists of:

* **Graph:** The network of vertices and edges.
* **Objective:** What we want to minimize or maximize.
* **Constraints:** Conditions that a valid solution must satisfy.

---

## 1. Minimum Spanning Tree (MST)

A Minimum Spanning Tree is a spanning tree of a connected, undirected, weighted graph having the minimum possible total edge weight.

Let's understand the terms:

* **Spanning:** Includes every vertex in the graph.
* **Tree:** Contains no cycles and is connected.
* **Minimum:** Has the smallest possible sum of edge weights.

For a graph containing $V$ vertices, a spanning tree contains exactly:

$$
V - 1 \text{ edges}
$$

Consider a network of four cities:

```
       4
   A ------- B
   | \       |
  2|  \5    |3
   |   \     |
   C ------- D
       6
```

The objective is to connect all four cities while minimizing the total connection cost.

One possible spanning tree is:

$$
(A,C), (B,D), (A,B)
$$

Its total weight is:

$$
2 + 3 + 4 = 9
$$

The minimum spanning tree selects the combination of edges with the smallest total weight while keeping the graph connected and cycle-free.

### Applications
* Designing cost-efficient communication networks.
* Connecting cities through roads or cables.
* Electrical network planning.
* Clustering and data analysis.

### Important Properties
* A spanning tree contains all vertices.
* It contains exactly $V - 1$ edges.
* It has no cycles.
* A connected weighted graph may have multiple minimum spanning trees if edge weights allow ties.
* For a disconnected graph, a minimum spanning forest is found instead of a single spanning tree.

## 2. Minimum Spanning Tree Algorithms

Two classical algorithms are used to find minimum spanning trees.

### 2.1 Kruskal's Algorithm
Kruskal's algorithm builds a minimum spanning tree by selecting edges in increasing order of weight.

**Approach:**
1. Sort all edges by increasing weight.
2. Select the smallest-weight edge.
3. Check whether adding it creates a cycle.
4. If it does not create a cycle, include it.
5. Repeat until $V - 1$ edges have been selected.

A Disjoint Set Union (DSU), also called Union-Find, is commonly used to detect whether two vertices already belong to the same component.

**Time Complexity:**

$$
O(E \log E)
$$

The sorting of edges is the dominant operation.

> **Intuition:** Keep selecting the cheapest available connection without creating a cycle.

### 2.2 Prim's Algorithm
Prim's algorithm grows a minimum spanning tree from a starting vertex.

**Approach:**
1. Start with any vertex.
2. Consider all edges connecting the current tree to vertices outside it.
3. Select the minimum-weight edge.
4. Add the new vertex and edge to the tree.
5. Repeat until all vertices are included.

With an adjacency list and binary min-heap, its commonly stated time complexity is:

$$
O((V + E) \log V)
$$

> **Intuition:** Keep expanding the existing tree through its cheapest available connection.

### Kruskal vs. Prim

| Feature | Kruskal | Prim |
| :--- | :--- | :--- |
| **Approach** | Select globally smallest eligible edge | Expand from an existing tree |
| **Starting vertex** | Not required | Required |
| **Main data structure** | Disjoint Set Union | Priority queue |
| **Common implementation**| Sort edges | Min-heap |
| **Suitable perspective** | Edge selection | Vertex expansion |

Both algorithms produce an MST for a connected, undirected weighted graph.

## 3. Maximum Flow

Maximum Flow is an optimization problem that determines the maximum amount of flow that can travel from a source vertex to a destination vertex in a network.

Each directed edge has a capacity that limits how much flow can pass through it.

Consider a transportation network:

```
       10
   S ------ A
    \       |
   5 \      | 4
      \     |
       B --- T
         8
```

Here:
* $S$ is the source.
* $T$ is the sink.
* Edge weights represent capacities.
* Flow cannot exceed the capacity of an edge.

The objective is to maximize the total flow from $S$ to $T$.

### Flow Constraints
Two important constraints must be satisfied:

1. **Capacity constraint:** The flow through an edge cannot exceed its capacity.

$$
0 \leq f(u,v) \leq c(u,v)
$$

Where $f(u,v)$ is the flow through the edge and $c(u,v)$ is the capacity of the edge.

2. **Flow conservation:** For every intermediate vertex, incoming flow must equal outgoing flow.

$$
\sum_u f(u,v) = \sum_w f(v,w)
$$

The source generates flow, and the sink receives flow.

### Maximum Flow Algorithms
* **Ford-Fulkerson:** Repeatedly finds an augmenting path from source to sink and sends additional flow through it.
* **Edmonds-Karp:** A Ford-Fulkerson implementation that uses BFS to find augmenting paths. Time complexity: $O(VE^2)$.
* **Dinic's Algorithm:** Uses BFS to construct a level graph and DFS to find blocking flows. Worst-case complexity: $O(V^2E)$.

### Applications
* Transportation and logistics.
* Communication networks.
* Supply chain optimization.
* Resource allocation.
* Matching and assignment problems.

## 4. Minimum Cut

A cut divides the vertices of a flow network into two groups:
* One containing the source.
* Another containing the sink.

The capacity of a cut is the sum of capacities of edges directed from the source side to the sink side. The minimum cut is the cut having the smallest possible capacity.

### Max-Flow Min-Cut Theorem
The maximum possible flow from source to sink is equal to the capacity of the minimum cut.

$$
\boxed{\text{Maximum Flow} = \text{Minimum Cut Capacity}}
$$

This is one of the fundamental results in network optimization.

> **Intuition:** The maximum amount of flow a network can carry is limited by its weakest separating cut.

### Applications
* Identifying bottlenecks in transportation networks.
* Finding network vulnerabilities.
* Partitioning networks.
* Understanding capacity limitations.

## 5. Shortest-Path Optimization

Shortest-path algorithms are also graph optimization methods because they minimize the total cost of travelling between vertices.

For example:
* **Dijkstra's algorithm:** Minimizes distance with non-negative edge weights.
* **Bellman-Ford:** Handles negative edge weights and detects reachable negative cycles.
* **Floyd-Warshall:** Computes shortest paths between all pairs of vertices.

*Note: The important distinction is that shortest-path optimization focuses on the cost of a route, whereas an MST focuses on the total cost of connecting all vertices.*

## 6. Travelling Salesperson Problem (TSP)

The Travelling Salesperson Problem asks:
Given a set of cities and the travel cost between each pair, what is the minimum-cost tour that:
1. Starts from a city.
2. Visits every other city exactly once.
3. Returns to the starting city.

Consider:

```
       A
      / \
     /   \
    B --- C
     \   /
      \ /
       D
```

The goal is to find the cheapest possible tour that visits all four cities and returns to the starting point.

The TSP is a famous combinatorial optimization problem. For the general optimization problem, finding an exact solution is computationally difficult. TSP is **NP-hard**.

### Approaches
* **Brute force:** Examine all possible tours.
* **Dynamic programming:** Use overlapping subproblems and stored results.
* **Branch and bound:** Eliminate solutions that cannot improve the current best.
* **Approximation algorithms:** Find solutions with guaranteed quality bounds for suitable variants.
* **Heuristics:** Find practical solutions without necessarily guaranteeing optimality.

### Applications
* Delivery route planning.
* Manufacturing and circuit-board drilling.
* Logistics and transportation.
* Scheduling and routing problems.

## 7. Graph Coloring

Graph coloring assigns colors to vertices such that no two adjacent vertices share the same color.

The minimum number of colors required for a valid vertex coloring is called the **chromatic number**, represented by:

$$
\chi(G)
$$

Consider:

```
A ----- B
| \     |
|  \    |
C ----- D
```

Adjacent vertices must receive different colors. However, non-adjacent vertices may share the same color.

### Applications
* Exam scheduling.
* Register allocation in compilers.
* Frequency assignment in wireless networks.
* Timetable generation.
* Conflict-free resource allocation.

> **Important Note:** Finding the chromatic number of a general graph is NP-hard. A greedy coloring algorithm can produce a valid coloring efficiently, but it does not always find the minimum number of colors.

## 8. Bipartite Matching

A bipartite graph is a graph whose vertices can be divided into two disjoint sets such that every edge connects a vertex from one set to a vertex in the other.

For example:
* One set contains employees.
* Another set contains available jobs.
* An edge indicates that an employee is eligible for a particular job.

The maximum matching problem seeks the largest possible set of edges such that no two selected edges share a vertex.

Consider:

```
Employees        Jobs

A ------------- X
 \              |
  \             |
   ------------ Y

B ------------- Y
 \              |
  ------------- Z
```

The objective is to assign employees to distinct jobs while maximizing the number of assignments.

### Types of Matching
* **Matching:** A set of edges with no shared endpoints.
* **Maximum matching:** A matching containing the largest possible number of edges.
* **Perfect matching:** A matching in which every vertex is matched.

### Algorithms
* Augmenting path algorithms.
* Hopcroft-Karp algorithm for maximum bipartite matching.
* Hungarian algorithm for the assignment problem with costs.

### Applications
* Employee-job assignment.
* Student-project allocation.
* College admissions.
* Resource allocation.
* Matching applicants with available positions.

## 9. Graph Optimization Problems at a Glance

| Problem | Objective | Common Algorithm |
| :--- | :--- | :--- |
| **Minimum Spanning Tree** | Minimize total connection weight | Kruskal, Prim |
| **Maximum Flow** | Maximize flow from source to sink | Ford-Fulkerson, Edmonds-Karp, Dinic |
| **Minimum Cut** | Minimize cut capacity | Max-flow/min-cut algorithms |
| **Shortest Path** | Minimize route cost | Dijkstra, Bellman-Ford, Floyd-Warshall |
| **Travelling Salesperson** | Minimize total tour cost | Dynamic programming, branch and bound |
| **Graph Coloring** | Minimize number of colors | Coloring algorithms and heuristics |
| **Bipartite Matching** | Maximize number of assignments | Hopcroft-Karp |

---

## 10. Important Distinctions

Some graph optimization problems may look similar, but their objectives are different:

| Problem | What are we optimizing? |
| :--- | :--- |
| **Shortest Path** | Cost of travelling between vertices |
| **Minimum Spanning Tree** | Total cost of connecting all vertices |
| **Maximum Flow** | Amount of flow through a network |
| **Minimum Cut** | Capacity of a separating cut |
| **TSP** | Cost of a complete tour |
| **Graph Coloring** | Number of colors needed |
| **Maximum Matching** | Number of compatible assignments |

*For example, an MST is not necessarily a shortest route connecting every pair of vertices. It minimizes the total weight of a spanning tree, not the distance between every pair of vertices.*

---

> **Key Takeaway:** Graph optimization transforms a network into a mathematical problem with an objective and constraints. Depending on the problem, we may want to connect everything at minimum cost, find the cheapest route, maximize transportation capacity, minimize conflicts, assign resources efficiently, or find an optimal tour. Different optimization problems require different algorithms because they optimize different objectives.

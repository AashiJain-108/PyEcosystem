# 07. Connectivity

Connectivity describes how vertices in a graph are connected to one another and whether paths exist between them. It helps us understand whether a graph forms one connected network or consists of multiple separate groups.

**Examples:**
* **Social Networks:** Determines whether people belong to one connected network or separate communities.
* **Computer Networks:** Helps determine whether devices can communicate.
* **Road Networks:** Helps identify whether locations remain reachable when roads are removed.

---

## 1. Connected Graph

An undirected graph is called **connected** if there exists a path between every pair of vertices. In other words, every vertex can be reached from every other vertex.

### Example 1: Connected Graph
```
A ----- B
|       |
|       |
C ----- D
```
*Every vertex is reachable from every other vertex, so the graph is connected.*

### Example 2: Disconnected Graph
```
A ----- B       D ----- E
        |
        C
```
*There is no path connecting the group $\{A, B, C\}$ to the group $\{D, E\}$. Therefore, the graph is disconnected.*

> **Important:** A graph containing only one vertex is considered connected because there is no pair of distinct vertices that cannot be connected.

---

## 2. Connected Components

A **connected component** is a *maximal connected subgraph* of an undirected graph.

### Key Terms:
* **Connected:** Every vertex in the subgraph can reach every other vertex.
* **Maximal:** No additional vertex from the original graph can be included without losing that connectivity.

### Example:
```
A ----- B       D ----- E
        |               |
        C               F

                H
```

This graph contains three connected components:
1. $\{A, B, C\}$
2. $\{D, E, F\}$
3. $\{H\}$

*Each component is internally connected, but there are no paths between different components.*

### Isolated Vertices
An **isolated vertex** is a vertex with a degree of zero (it has no edges connecting it to other vertices). An isolated vertex forms a connected component by itself (e.g., vertex $H$ above).

---

## 3. Connectivity in Directed Graphs

For directed graphs, connectivity requires additional distinctions because edges have directions.

Consider:
```
A → B → C
```
Although $A$ can reach $C$, $C$ cannot necessarily reach $A$.

### 3.1 Weakly Connected
A directed graph is **weakly connected** if replacing all directed edges with undirected edges produces a connected graph.

* **Example:**
  ```
  A → B ← C
  ```
  Ignoring directions:
  ```
  A — B — C
  ```
  *Therefore, the graph is weakly connected.*

### 3.2 Strongly Connected
A directed graph is **strongly connected** if every vertex can reach every other vertex by following the direction of the edges.

* **Example:**
  ```
  A → B
  ↑   ↓
  C ←
  ```
  *Here, every vertex can reach every other vertex through directed paths. Therefore, the graph is strongly connected.*

#### Key Distinction:
| Property | Meaning |
| :--- | :--- |
| **Weakly connected** | Connected when edge directions are ignored |
| **Strongly connected** | Every vertex can reach every other vertex following edge directions |

### Strongly Connected Components (SCC)
A **strongly connected component (SCC)** is a maximal subgraph in which every vertex can reach every other vertex through directed paths. A directed graph can contain multiple strongly connected components.

---

## 4. Bridges (Cut Edges)

A **bridge** is an edge whose removal increases the number of connected components in an undirected graph.

### Example:
```
A ----- B ----- C
        |
        D
```
* The edge connecting $A$ and $B$ is a bridge.
* If we remove it:
  ```
  A       B ----- C
          |
          D
  ```
* The graph splits into two connected components: $\{A\}$ and $\{B, C, D\}$.

### Why Bridges Matter
Bridges help identify critical connections in networks:
* A road whose closure disconnects a region.
* A communication link whose failure separates parts of a network.
* A connection that holds two groups of a network together.

---

## 5. Articulation Points (Cut Vertices)

An **articulation point** is a vertex whose removal increases the number of connected components in an undirected graph. Removing a vertex also removes all edges incident to it.

### Example:
```
A ----- B ----- C
        |
        D
```
* Vertex $B$ is an articulation point.
* If $B$ is removed:
  ```
  A       C

          D
  ```
* The graph splits into three connected components: $\{A\}$, $\{C\}$, and $\{D\}$.

### Why Articulation Points Matter
They help identify critical vertices in networks:
* A central router whose failure disconnects devices.
* A key person connecting otherwise separate groups in a social network.
* A critical junction connecting different parts of a transportation network.

---

## 6. Edge Connectivity

Edge connectivity measures how many edges must be removed to disconnect a connected graph. It is commonly represented by:

$$\lambda(G)$$

For a connected, nontrivial undirected graph, it is the minimum number of edges whose removal makes the graph disconnected.

### Example:
```
A ----- B
|       |
|       |
D ----- C
```
* Removing only one edge does not disconnect this cycle.
* Removing two suitable edges can disconnect it.
* Therefore: $\lambda(G) = 2$.

> A graph with higher edge connectivity is generally more resilient to edge failures.

---

## 7. Vertex Connectivity

Vertex connectivity measures how many vertices must be removed to disconnect a connected graph. It is commonly represented by:

$$\kappa(G)$$

For a connected graph with at least two vertices, it is the minimum number of vertices whose removal disconnects the graph or leaves a single vertex.

### Example:
* In a cycle containing four vertices, removing one vertex does not disconnect the remaining graph.
* Removing two suitable vertices can disconnect it.
* Therefore: $\kappa(G) = 2$.

> A graph with higher vertex connectivity is generally more resilient to vertex failures.

---

## 8. Connectivity vs. Reachability

| Concept | Meaning |
| :--- | :--- |
| **Reachability** | Whether a particular vertex can reach another vertex |
| **Connectivity** | Whether the graph satisfies a broader connection property |
| **Connected component** | A maximal connected group of vertices |
| **Strong connectivity** | Mutual reachability between every pair of vertices in a directed graph |

### Example:
```
A ----- B       C ----- D
```
* $A$ can reach $B$, but cannot reach $C$.
* $A$ and $B$ belong to the same connected component.
* $C$ and $D$ belong to another connected component.
* The overall graph is disconnected.

---

## 9. Finding Connectivity

Graph traversal algorithms can help determine connectivity.

### Undirected Graphs:
1. Choose any starting vertex.
2. Run BFS or DFS.
3. Count the number of visited vertices.
4. Compare it with the total number of vertices.
   * If every vertex is visited, the graph is **connected**.
   * Otherwise, it is **disconnected**.

*To find all connected components, repeat the traversal from each unvisited vertex until every vertex has been visited.*

### Directed Graphs:
Strongly connected components require algorithms such as:
* Kosaraju's algorithm
* Tarjan's algorithm

## 10. Quick Comparison

| Concept | What it tells us |
| :--- | :--- |
| **Connected graph** | Whether all vertices are mutually reachable in an undirected graph |
| **Connected components** | Number of separate connected groups |
| **Weak connectivity** | Connectivity after ignoring edge directions |
| **Strong connectivity** | Mutual directed reachability |
| **Bridge** | A critical edge whose removal disconnects the graph |
| **Articulation point** | A critical vertex whose removal disconnects the graph |
| **Edge connectivity** | Minimum number of edges to remove to disconnect a graph |
| **Vertex connectivity** | Minimum number of vertices to remove to disconnect a graph |

---

## 11. Applications of Connectivity

Connectivity is important in several real-world systems:

* **Social Networks:** Identifying isolated groups and people connecting different groups.
* **Computer Networks:** Understanding network reliability and communication failures.
* **Transportation Networks:** Finding critical roads, bridges, and junctions.
* **Infrastructure:** Identifying vulnerable components in power grids and communication systems.
* **Network Science:** Understanding the structure and resilience of complex networks.

---

> **Key Takeaway:** Connectivity helps us understand the structure and resilience of a graph. It tells us whether a network is connected, how many separate components exist, and which vertices or edges are critical to keeping the network connected.
